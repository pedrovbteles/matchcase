Projeto em Python desenvolvido para explorar e demonstrar o uso do novo comando match-case (estrutura de pattern matching) introduzido a partir da versão 3.10 da linguagem.

📌 Sobre
Este projeto contém exemplos práticos e educativos do uso do match-case, oferecendo uma forma clara de entender o comportamento dessa nova estrutura de controle de fluxo.

🚀 Tecnologias
Python 3.10 ou superior

📂 Estrutura
matchcase/
├── main.py → Arquivo principal com exemplos de match-case
├── utils.py → Funções auxiliares (se houver)
└── README.md → Documentação do projeto

▶️ Como executar
Certifique-se de ter o Python 3.10 ou superior instalado.

Clone o repositório:
git clone https://github.com/pedrovbteles/matchcase.git
cd matchcase

Execute o script principal:
python main.py

🧠 Objetivos de aprendizado
Entender o funcionamento do match-case

Comparar com estruturas tradicionais como if-elif-else

Praticar pattern matching com tipos variados: int, str, tuple, dict, etc.
